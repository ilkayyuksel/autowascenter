# Deprecation Cleanup Map

Phase 7C removes the Supabase, Lovable and Cloudflare Workers runtime and build dependencies. The decisions below were made from a full repository search **before** any change. Search terms:

`@supabase/supabase-js`, `supabase.from`, `supabase.auth`, `supabase.storage`, `createClient`, `VITE_SUPABASE`, `SUPABASE_`, `src/integrations/supabase`, `supabase/`, `@lovable.dev`, `@cloudflare/vite-plugin`, `cloudflare-module`, `wrangler`, `LOVABLE_SANDBOX`, `lovable.dev`, `lovable.app`, `r2.dev`, `previewAuthStorage`, `auth-middleware`, `client.server`, plus a case-insensitive search for `lovable|cloudflare|supabase|wrangler`.

The search excluded `node_modules/`, `.git/`, `.output/` and `.wrangler/` (build artefacts).
